需要时按上游地址浅克隆到本地（相应目录已加入 `.gitignore`）：

| 字典 | 上游仓库 |
| --- | --- |
| fuzzDicts | https://github.com/TheKingOfDuck/fuzzDicts |
| kerberos_enum_userlists | https://github.com/attackdebris/kerberos_enum_userlists |
| n0kovo_subdomains | https://github.com/n0kovo/n0kovo_subdomains |
| username-anarchy | https://github.com/urbanadventurer/username-anarchy |

```bash
git clone --depth 1 https://github.com/TheKingOfDuck/fuzzDicts dicts/fuzzDicts
```
